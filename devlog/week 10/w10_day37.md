What I learned:
- SHAP explains a prediction by splitting it into per-feature contributions that ADD UP to the output (Shapley values from game theory - each feature's fair average marginal contribution). Beeswarm: model leaned on Return/RSI/MACD/lagged returns, calendar dummies negligible, Log Return ~0 (redundant). But colors are smeared across both sides of 0 = no clean directional signal. High SHAP = "the model used it," NOT "it predicts the future"
- Class weights (scale_pos_weight = neg/pos ratio ~0.85) rebalance the up/down prediction mix but don't create edge - cv logloss stayed at ~0.693. The imbalance was never the problem
- Bootstrapping: I only saw history once, so resample the daily returns WITH REPLACEMENT thousands of times, compute the Sharpe each time -> that spread is the sampling distribution. Take the 2.5/97.5 percentiles = 95% CI
- Read the result: every 95% CI includes 0, even QQQ (Sharpe 1.35, ci_low -0.01). So no Sharpe is statistically distinguishable from zero OR from buy-and-hold. The CIs are ~2.7 wide -> with ~500 days you can't detect an edge even if one existed
