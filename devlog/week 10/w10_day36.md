- Result: no consistent edge across windows either - the no-edge finding is now robust across time

What I learned:
- Walk-forward = many rolling train/test windows marching through time, giving a DISTRIBUTION of out-of-sample results instead of one fragile split. Always train-on-past/test-on-future (no leakage), which is why random k-fold is banned for time series
- Pool all tickers into ONE date-indexed frame (concat + sort_index, keep the dates) then slice by date window - can't use data_split() here because it strips the dates
- Read the plot by comparing accuracy to EACH window's base rate: above in 2 windows, below in 2, averaging slightly below = no consistent edge. Accuracy stays ~0.5 while the base rate swings 0.47-0.59, so the model isn't reading the regime, just guessing
