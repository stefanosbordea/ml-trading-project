What I learned:
- Per-asset generalization asks whether the failure is universal or asset-specific. A model that "works on some tickers but not others" is suspicious; one that sits at base rate on ALL of them is a clean, robust negative result
- To do it per ticker I had to evaluate on each ticker's OWN test slice (data_split pools everything and loses ticker identity), using the same last-20% cut as the index() function in backtest.py
- Results: accuracy <= base rate on all 7 tickers (never beats "always predict majority"), AUC in 0.495-0.543 = ~coin flip on every asset. The few AUCs slightly above 0.5 (QQQ, NVDA) are noise at ~500 rows, consistent with the huge bootstrap Sharpe CIs
- The CONSISTENCY is the point: it fails identically across equities and crypto -> rules out asset-specific edge -> the negative result is robust, not an averaging artifact
- F1 came out 0.6-0.72 again (base-rate inflation, not skill)
